How to send a message

POST one XML document to {{ endpoint }} with the API key in the X-API-Key header:

curl -i -X POST '{{ endpoint }}' \
  -H 'X-API-Key: YOUR_API_KEY' \
  -H 'Content-Type: application/xml' \
  --data-binary @message.xml

You can also send one by hand from /docs. A Subject containing [reject] is refused (422); one containing [fail] gets a 503 that is not stored.
